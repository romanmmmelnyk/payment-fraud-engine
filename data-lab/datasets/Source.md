# Dataset Source

I did not create this dataset. I’m using it as a public practice dataset for my own data analysis and fraud detection research.

The dataset was created and published by **isaBBaggin** on Kaggle under the name **“Transaction Data for fraud analysis”**.

Original source: [Kaggle](https://www.kaggle.com/datasets/isabbaggin/transaction-fraudulent-financial-syntheticdata)

All credit for the original dataset goes to the author. My work focuses on analysing the data, exploring payment behaviour, and using it as a foundation for developing the ideas behind the Real-Time Payment Fraud Engine.
